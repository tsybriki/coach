Раскладка программы Дэниэлса по фазам

Неделя сезона → фаза → неделя программы → чей план применяется. Числа — из рабочего кода (MethodPlan.schedule_for).
Правило. При сроке больше 24 недель фазы собираются из своих недель программы подряд (I — 1–6, II — 7–12, III — 13–18, IV — 19–24). Лишние недели идут по кругу через фазы II, III, IV и стоят у края своей фазы: в конец для II и III, в начало для IV. План лишней недели — с того же края: одна лишняя неделя берёт неделю с края (II — 12, III — 18, IV — 19), две и больше — край фазы по кругу (II — 11, 12; III — 17, 18; IV — 19, 20).
