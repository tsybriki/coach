# coach-onboarding

Первоначальное заполнение state/ из архивов, интервью, истории.

**Использует:** прямой доступ к state/athlete.json, state/constraints.json, state/season_plan.json.
**Триггеры:** «онбординг», «инициализация», «импорт из истории».
**Вход:** источники (Garmin, Intervals.icu, история писем, интервью).
**Выход:** заполненные state-файлы + audit.

## Запрещено

- Трогать существующие goals[] без явного подтверждения.
- Писать промпты руками.
